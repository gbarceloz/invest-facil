# Checklist de revisão — vídeo educativo

## Factual

- [ ] Cada afirmação factual tem fonte primária registrada.
- [ ] Números/exemplos são hipotéticos e rotulados.
- [ ] Nenhuma promessa de rentabilidade.
- [ ] Nenhuma recomendação individual de compra/venda.
- [ ] Riscos e possibilidade de perda explicados.

## Editorial

- [ ] Linguagem adequada a iniciantes.
- [ ] Um conceito por vídeo.
- [ ] Gancho nos primeiros 5 s.
- [ ] Aviso educativo presente.
- [ ] Português revisado.

## Técnico

- [ ] 1080×1920, 30 fps, H.264/AAC.
- [ ] ≤ 3 min e ≤ 50 MB.
- [ ] Legendas sincronizadas e legíveis.
- [ ] Áudio sem clipping; voz inteligível.
- [ ] Texto dentro das safe zones.
- [ ] Arquivo abre em player comum.

## Direitos

- [ ] Imagens, ícones e trilha com licença registrada.
- [ ] Nenhuma marca de terceiro sem autorização.
- [ ] Créditos no metadata.

## Publicação

- [ ] Upload via backend (ADMIN) no Supabase Storage.
- [ ] Reprodução no frontend em desktop e mobile.
- [ ] Metadados da aula atualizados.
- [ ] Draft editável e SRT preservados.
