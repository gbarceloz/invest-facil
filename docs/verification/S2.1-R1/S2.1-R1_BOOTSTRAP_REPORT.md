## 4. Execução do bootstrap de migration

A lógica equivalente ao script original foi executada em **uma única sessão psql**, com transação explícita, `ON_ERROR_STOP=1` e GUC `app.migration_password` definida localmente. O arquivo SQL original não foi editado.

Sequência executada:

```text
BEGIN
SET LOCAL app.migration_password
CREATE ROLE investfacil_app NOLOGIN (se ausente)
CREATE ROLE investfacil_test_guest NOLOGIN (se ausente)
CREATE ROLE investfacil_migrate LOGIN INHERIT (se ausente)
ALTER ROLE investfacil_migrate LOGIN INHERIT / PASSWORD (via GUC)
GRANT CONNECT, CREATE ON DATABASE postgres TO investfacil_migrate
GRANT investfacil_migrate TO postgres WITH SET TRUE, INHERIT FALSE, ADMIN FALSE
CREATE SCHEMA investfacil
ALTER SCHEMA investfacil OWNER TO investfacil_migrate
GRANT USAGE, CREATE ON SCHEMA investfacil TO investfacil_migrate
REVOKE investfacil_migrate FROM postgres GRANTED BY CURRENT_USER
verificações DO $$
COMMIT
```

Resultado: **COMMIT** bem-sucedido. Houve apenas o aviso `no privileges were granted for "investfacil"` no `GRANT USAGE, CREATE` porque o owner já possui esses privilégios; não é falha.

## 6. Membership temporária e revogação

### Antes

`investfacil_migrate` não existia; não havia membership.

### Durante

Foi concedido exatamente:

```sql
GRANT investfacil_migrate TO postgres WITH SET TRUE, INHERIT FALSE, ADMIN FALSE;
```

### Depois

Consulta a `pg_auth_members`:

| Granted role | Member | Grantor | SET | INHERIT | ADMIN |
|---|---|---|---:|---:|---:|
| `investfacil_migrate` | `postgres` | `supabase_admin` | false | false | true |
| `investfacil_app` | `investfacil_runtime` | `postgres` | true | true | false |

A linha remanescente é a associação administrativa automática do `supabase_admin`, preservada conforme a instrução. A concessão temporária feita por `postgres` foi removida.

```text
pg_has_role('postgres', 'investfacil_migrate', 'SET') = false
```

O `postgres` não consegue mais assumir `investfacil_migrate` com SET ROLE.

Risco residual: `postgres` mantém `ADMIN OPTION` sobre `investfacil_migrate` (grantor `supabase_admin`), mas sem SET/INHERIT. Isso foi expressamente preservado; não foi usado para elevar privilégios.
